# Vocabulary protocol alignment review v1

Status: **audit delta implemented; independent approval pending**.

This review locks the v1 protocols and production interaction source before
applying four narrow amendments. V1 remains historical and unchanged.

1. The pretest product probe now uses the actual default first-stage actions:
   `I know it`, `Not sure`, `I don’t know`, and the separate exclusion action.
   Optional typed meaning stays optional. The independent criterion remains the
   recall/translation task.
2. Repeat-response `E1` and `E2` now mean the complete production event:
   pre-reveal action, optional typed meaning, reveal, post-reveal verification
   when known was claimed, and the exact Core evidence-category mapping.
3. The repeat-response denominator now says **distinct eligible
   participant-item records**, not independent records; participant/document/item
   dependence remains mandatory.
4. The frozen tail-risk formula is unchanged. Its clearer display alias is
   `conditionalTargetShortfall`; a separate threshold-excess severity formula
   is defined but remains optional and unapproved for release.

No statistical value, prompt timing, sample size, consent operation, collection
authorization, production behavior, confirmation access, or release-holdout
access changes in this amendment. Independent approval remains outstanding.
